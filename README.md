# 🔐 Random Password Generator

A simple **Random Password Generator** built using Python and Tkinter.
This application allows users to enter a desired password length and generate a strong random password containing letters, numbers, and special characters.

## 🚀 Features

* Generate random passwords instantly
* Choose the password length
* Includes:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* Minimum password length of 4 characters
* Simple and user-friendly GUI
* Error handling for invalid input

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – GUI development
* **Secrets** – Secure random password generation
* **String** – Character sets

## 💡 How It Works

1. Enter the desired password length.
2. Click **Generate Password**.
3. The program creates a random password.
4. The generated password is displayed in the application.

The program combines letters, digits, and punctuation characters and uses `secrets.choice()` to select characters for the password.

## 📸 Output

The application provides a simple window with:
